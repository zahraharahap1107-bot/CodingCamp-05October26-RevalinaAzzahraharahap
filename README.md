# To-Do List Life Dashboard

A minimalist web application with Light & Dark mode support, built for RevoU Coding Camp Mini Project.

## 🚀 Features
- ⏰ Real-time Digital Clock & Dynamic Greeting
- 👤 Editable Profile Name (Saved in Local Storage)
- ⏱️ Focus Timer (Pomodoro Widget)
- 📝 Interactive To-Do List with Task Sorting
- 🔗 Customizable Quick Links
- 🌓 Light & Dark Mode Toggle

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla ES6)
